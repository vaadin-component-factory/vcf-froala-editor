## Summary

Froala WYSIWYG Editor as a Vaadin Flow field, with toolbar, plugins, uploads and a Lumo look.

## Description

A Vaadin Flow add-on that wraps the Froala WYSIWYG Editor 5.4.0 as a Java component.

- A real Vaadin field. The value is HTML, with value change modes, label, helper text,
  read-only, disabled and invalid like Vaadin's other fields.
- Froala options in Java. Plugins, toolbar layout, popup buttons, text direction and
  languages, with constants for Froala's names.
- Own toolbar commands with Vaadin icons and keyboard shortcuts, which open a Dialog or
  Popover or run any server code.
- Image, file and video uploads through Flow upload handlers.
- A theme that follows Lumo, light and dark, plus Froala's own themes.
- FroalaViewer renders the HTML outside an editor with the same styles.

Add-on 2.x needs Java 21 or newer and Vaadin 25.3. Add-on 1.x is the line for Java 17 and Vaadin 24.10.
